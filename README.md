One letter, A to Z, standing for the word that describes my day.

**My entry: `U` — for "unhinged".** The day the plan fell apart before
breakfast, the group chat went feral, and everything happened at once.
Vivid, funny, and true.

## How it works

`main.ts` (Node, stdlib only) writes exactly one character — the letter `U`
— to `$MAKEFUN_OUTPUT_DIR/entry.txt` and nothing else. A gate guard in the
code validates the entry is exactly one letter A–Z before writing.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/one-letter-day-out node main.ts
cat /tmp/one-letter-day-out/entry.txt
# U
```
